# R3 risk register

Type: reference. Updated 2026-09-23. Likelihood/impact are planning judgments.

| Risk | Impact / early signal | Response / owner |
| --- | --- | --- |
| Product resembles stronger existing tutors/labs | Users cannot name a benefit beyond appearance | Fair same-lab comparator; focus on practical artifact, continuity and tutor evidence; product owner |
| Lesson does not fit a real teaching need | Tutor finds scenario arbitrary or misaligned | Discovery and content review before expanding features; content owner |
| Power/energy simulation misleads | Unit/boundary error or implied real-device behavior | Independent reference values, explicit idealized model, educator review; engineering/content |
| Trial-and-error passes without understanding | Many rapid edits, weak changed-task performance | Observe process, targeted comparison and distinct review; no mastery claim; research owner |
| Voice/hosting SDK incompatibility | No working tool action by early gate | R06 spike, direct SDK speech path, bounded bridge; explicit scope/claim change if necessary |
| Account/credit restrictions | Received code not redeemable or services unavailable | Inspect actual account/terms at deployment gate; prepare concrete upgrade decision; owner |
| 130h exceeds available month | Core milestones slip before Oct 5 | Cut P1, use contingency on blockers, re-estimate honestly; delivery owner |
| Assistance leaks into independent attempt | Agent gives optimal schedule or hidden source | Server phase permissions and retrieval scopes; label assisted transition; engineering |
| Persisted state or identity error | Another guest's report, stale voice overwrite | Isolated capabilities, transaction/revision checks and ticket validation; engineering |
| Audio/cost growth | Reconnect loops, long idle sockets, replayed context | Duration/usage reservations, global limits, close idle streams; engineering |
| Weak participant access | No real tutor/learners by Oct 10 | Start recruitment preparation early; report actual count, never invent validation; owner |
| Judge cannot use app | Expired link, unavailable live model, setup failure | Stable hosted target, offline exercise and source/video, clear free access; release owner |
| Misleading competition claim | Optional features narrated as shipped; simulated Alexa presented as native | Evidence map and release claim audit; owner |
| Date/form changes | Official pages disagree or fields change | Recheck near submission; maintain broader judge window; owner |

Escalate only the specific decision that blocks progress, after making the work concrete and reviewable. Do not turn this risk register into a repeated approval checklist for already authorized local work.
