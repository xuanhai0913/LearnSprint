## Required package and forms

Prepare a working project; GitHub source/assets/setup; English description/materials or translations; a publicly viewable YouTube/Vimeo demonstration shorter than three minutes; selected track/challenge fields; tool feedback; and a clear new/existing-work declaration. Provide free evaluation access. [Submission requirements](https://amazonappdev2026.devpost.com/).

The tool-feedback answers cover purpose, what worked, what needs improvement, onboarding and whether we would use the tool again. AWS Builder needs the actual AWS use explained. Optional friction entries need specific actionable observations. [Official rules](https://amazonappdev2026.devpost.com/rules).

The owner already reports receiving the $150 code; no duplicate credit form is needed for planning. Verify redemption/expiry separately. Final eligibility, rights and terms statements must match the real participants and delivered project. Winner payment/verification paperwork is conditional on selection, not a build prerequisite.
