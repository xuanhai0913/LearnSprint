## Capture notes

- Use prepared fictional demo shifts, or rehearse a fresh shift with the same facts. Do not edit browser state or splice a result that was not produced by the app.
- Record visible clicks, source labels, the changed ETA, exact agreement and handoff. Show a single clear proposal Apply/Undo without spending a new AI call if the saved assisted shift is used.
- The script does not require Sonic. The current hosted microphone path lacks a successful browser receipt; replace the typed-proposal shot with voice only after a verified session.
- Label any time compression. Keep numbers legible and include English captions. Hide AWS account IDs, tokens, cookies, credit codes and private files.
- Do not claim that this video proves learner outcomes. A practitioner/learner pilot is still planned.
